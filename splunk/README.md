# Splunk Dashboard Examples

Examples of Splunk dashboards developed for monitoring, analytics and operational troubleshooting.

## Dashboard 01 – Applications Monitoring

### Objective

Monitor key Applications and infrastructure metrics and provide an operational view for troubleshooting.

### Key areas

- Service health
- KPI monitoring
- Error Distribution
- Trends
- Incident investigation

### Technologies

- Splunk
- SPL
- JSON
- REST API
