# Splunk Dashboard Examples

Examples of Splunk dashboards developed for monitoring, analytics and operational troubleshooting.

## Dashboard 01 – Applications Monitoring

### Objective

Monitor key Applications and infrastructure metrics and provide an operational view for troubleshooting.

### Key areas

- Service health
- KPI monitoring
- Error Distribution
- Trends
- Incident investigation

### Technologies

- Splunk
- SPL
- JSON
- REST API

### My Contribution

I designed the dashboard structure, defined the relevant metrics and queries, and created visualizations to help technical teams quickly identify anomalies and investigate service-related issues.
